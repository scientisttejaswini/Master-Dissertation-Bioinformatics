# Master-Dissertation-Bioinformatics
MSc Bioinformatics dissertation - kinase signalling and machine learning

Predicting Kinase Activity from Phosphosite Measurement Using Machine Learning

This MSc Bioinformatics dissertation investigates whether kinase-specific phosphorylation patterns can predict KSEA-derived kinase activity using supervised machine learning. The study analyses phosphoproteomic data from three cell lines and evaluates eight regression algorithms using five-fold cross-validation and independent test-set performance.
